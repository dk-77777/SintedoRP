# Paleta laranja do Conecta SINTEDORP

A identidade usa laranja queimado para ações e navegação, marfim nas superfícies e carvão quente nos destaques. Os tokens ficam em `src/styles/tokens.css` e são compartilhados pela aplicação e pela demonstração.

| Uso | Cor |
| --- | --- |
| Marca, botões e links | `#AF4513` |
| Botão ao passar o mouse | `#923B10` |
| Fundo principal | `#FCFAF7` |
| Superfícies marfim | `#F6EEE5` |
| Destaque suave | `#FAE6D8` |
| Texto principal | `#2D241F` |
| Texto secundário | `#75675D` |
| Painel escuro | `#33261F` |
| Destaque no painel escuro | `#F4AD78` |

Estados de sucesso, erro e informação mantêm cores próprias para distinguir os resultados das ações. Os indicadores de foco usam laranja sobre superfícies claras e pêssego no painel escuro.

## Contraste

Os pares principais atendem a 4,5:1 para texto normal: branco no botão laranja (5,70:1), laranja no marfim (4,96:1), laranja no destaque suave (4,72:1) e texto secundário no marfim (4,74:1). As bordas de controles sobre branco têm contraste de 4,00:1. Essas medições cobrem os pares definidos pela paleta; não constituem uma auditoria completa de acessibilidade.

A prévia HTML e as capturas usam a mesma paleta do aplicativo. Todas as telas de apresentação utilizam dados fictícios.
